## Agent skills

### SmartDCA research workflow

When orienting, selecting, executing, reviewing, or resolving SmartDCA work, read `.scratch/smartdca/map.md` and `docs/agents/wayfinder-ticket-workflow.md` before changing a ticket.

### Issue tracker

Wayfinder maps and tickets live under `.scratch/smartdca/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The project uses the standard five-role triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context research project using root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Verification

When changing a proof, theorem ticket, score definition, or accounting identity, run the linked check under `reproducibility/checks/` and then run every check before publishing.
